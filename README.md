## 개인 포트폴리오 (반응형)

### 실행 방법
- **`index.html` 파일을 브라우저로 열기** (더블클릭)

### 구성
- `index.html`: 메인 페이지
- `styles.css`: 모던 UI 스타일(반응형 포함)
- `main.js`: 모바일 내비(햄버거) 토글 + 연도 자동 표기
- `assets/mascot.svg`: 예시 이미지(대체용)

### “한교동 이미지” 넣는 방법
저작권/라이선스 문제를 피하기 위해 기본값은 **대체용 예시 SVG**입니다.

원하는 이미지를 사용하려면 아래 중 하나로 교체하세요.
- **가장 쉬운 방법**: `assets/mascot.svg`를 본인 이미지로 교체(파일명 유지)
- 또는 `index.html`에서 아래 경로를 원하는 파일로 바꾸기:
  - `./assets/mascot.svg`
